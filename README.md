# walkersedgefarm.com

Website for Walker's Edge Farm, Louisburg, KS. Plain static HTML/CSS/JS served by GitHub Pages (custom domain via Cloudflare).

- Pages: `index.html`, `order.html`, `animals.html`, `about.html`, `contact.html`, `thank-you.html`, `404.html`
- Styles: `css/styles.css` · Scripts: `js/main.js` · Photos: `img/` (WebP + JPEG)
- Forms post to FormSubmit (walkersedgefarm@gmail.com).

To update goats for sale, prices, or hours, edit the matching text in the HTML files.
The previous site is preserved on the `legacy-site` branch.
